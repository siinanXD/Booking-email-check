# Kontext — Booking-email-check

Was Agenten ueber dieses Projekt wissen muessen und nicht aus dem Code
ablesen koennen.

**Keine Wiederholung von `AGENTS.md`.** Dort steht, was das Projekt ist. Hier
steht, was beim Arbeiten daran zu beachten ist und sich nicht aus dem Code
ergibt.

## Was hier hingehoert

- Fachbegriffe, die im Code anders heissen als im Gespraech
- Historische Gruende fuer Entscheidungen, die heute seltsam wirken
- Fallstricke, die schon einmal Zeit gekostet haben
- Wer oder was von einer Aenderung betroffen ist

## Was hier nicht hingehoert

- Zugangsdaten, Schluessel, Tokens — niemals
- Inhalte aus `.env`
- Kopien der Projektbeschreibung
